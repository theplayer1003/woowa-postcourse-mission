# 요구 사항 정리, 기능목록 정리
- [ ] 시간은 24시간 형식만 사용한다
- [ ] 교육 시간은
	- [ ] 월요일 13시 부터 18시 까지
	- [ ] 화요일 부터 금요일 까지는 10시 부터 18 시 까지
	- [ ] 각 교육 시간으로부터
		- [ ] 5분 초과 시 지각
		- [ ] 30분 초과 시 결석
- [ ] 등교하지 않아 출석 기록이 없으면 결석 처리 한다
	- [ ] 등교를 하지 않으면 기록이 등록되지 않는다
- [ ] 결석 회수가 5회를 초과하면 제적 한다
- [ ] 지각 3회는 결석 1회 로 계산한다
	- [ ] 결석이 2회 이상이면 경고 대상자
	- [ ] 결석이 3회 이상이면 면담 대상자
	- [ ] 결석이 5회 이상이면 제적 대상자
- [ ] 캠퍼스 운영 시간은 매일 8시 부터 23 시 까지다
- [ ] 주말 및 공휴일에는 출석을 받지 않는다
	- [ ] 공휴일을 어떻게 표현하지? 테스트 코드에는 12월 고정인데 하드 코딩을 해야할까?
- [ ] 시스템이 시작되면 attendances.csv 파일에서 파일을 읽어 크루들의 출석 기록을 초기화한다
- [ ] 프로그램은 사용자가 종료될 때까지 종료되지 않는다
	- [ ] 기능을 무사히 수행하면 초기 화면으로 돌아간다
	- [ ] 사용자가 잘못된 값을 입력할 경우 `[ERROR] ` prefix 와 함께 `IAE` 를 발생시키고 애플리케이션은 종료된다
		- [ ] 예외를 캐치하지 말고 최종적으로 던져서 뻗어야한다

- [ ] 출석 확인(등록)
	- [ ] 닉네임과 등교 시간을 입력 받는다
		- [ ] 해당 닉네임이 기존 목록에 있는지 검증한다
	- [ ] 출석이 등록되면 결과를 출력한다
		- [ ] Dto에 월,일,요일,시간,출석or결석 상태가 담긴다
	- [ ] 이미 기록이 있다면 등록 할 수 없으며 수정 기능을 이용하도록 안내한다
		- [ ] 가지고 있는 리스트에서 같은 날짜의 출석 기록이 있는지 검증한다
1. 서비스는 닉네임과 등교 시간이 담긴 dto를 넘겨 받는다
2. 서비스는 Crews에게 해당 닉네임을 통해 크루가 있는지 확인하고 없으면 예외 처리
	1. Crews는 findByName 으로 대상을 찾아서 있으면 반환, 없으면 예외처리
	2. 반환 값을 사용할지 말지는 바깥 코드의 소관이다
3. 서비스는 해당 Crew에게 출석 기록 중 같은 날짜의 출석 기록이 있는지 확인하도록 요청
	1. Crew는 있으면 반환 없으면 옵셔널
4. 서비스는 있으면 예외처리
5. 서비스는 Crew 에게 등교 시간 넘겨주며 추가하도록 요청
	1. Crew는 등교 시간과 `now()` 로 규칙 검사... 당일 출근 시간과의 차이를 받아 Attendance 에게 생성 요청

- [ ] 출석 수정
	- [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력 받는다
		- [ ] 해당 닉네임이 기존 목록에 있는지 검증한다
		- [ ] 수정하려는 날짜가 기존 목록에 있는지 검증한다
		- [ ] 등교 시간이 우테코 운영 시간인지 검증한다
	- [ ] 변경에 성공하면 이전과 이후의 결과를 같이 출력한다
		- [ ] `12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!`

- [ ] 크루별 출석 기록 확인
	- [ ] 닉네임을 입력 받는다
	- [ ] 닉네임을 통해 출석 기록을 조회해
		- [ ] `월 일 요일 시간 상태` 를 출력한다
		- [ ] 결석한 날의 시간은 `--:--` 로 출력한다
		- [ ] 최종 출석, 지각, 결석 회수를 카운트한다
		- [ ] 제적 상태를 표시한다
			- [ ] 경고, 면담, 제적 대상 여부
	- [ ] 조회하는 전날까지의 크루 출석 기록으로 판단한다

- [ ] 제적 위험자 확인
	- [ ] 조회하는 전날까지의 크루 출석 기록으로 판단한다
	- [ ] 제적, 면담, 경고 대상자 순으로 출력한다
		- [ ] 지각을 결석으로 환산한 총 결석 회수에 의해 결정된다
		- [ ] 총 결석 회수를 내림차순한다
	- [ ] 출석 상태가 같으면 닉네임으로 오름차순 한다
		- [ ] 총 결석으로 내림차순하고 이름으로 오름 차순

- [ ] csv 파일 수정 금지
- [ ] 지정된 예외 코멘트
