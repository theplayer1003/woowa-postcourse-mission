# 출석 시스템
- 출석 기록을 토대로 현재까지의 crew 들 출석 상태를 파악
- 크루들의 근태 관리


- 출석은 크루가 시스템에 출석 데이터를 저장한 시점을 기준으로 한다
- 24시간 형식을 이용한다
    - "22:30"
- 시작 시간으로부터 5분 초과는 지각
- 시작 시간으로부터 30분 초과는 결석
- 등교하지 않아 기록이 없으면 결석
- 출석 결과에 따른 제재
    - 결석 2회시 경고 대상자
    - 결석 3회시 면담 대상자
    - 결석 5회 초과시 제적 대상자
- 캠퍼스 운영 시간은 08:00 ~ 23:00
- 주말, 공휴일은 출석을 받지 않는다
- 12월 출석 기록은 csv 파일에 있다
- 프로그램은 사용자가 종료할때까지 종료되지 않는다
    - 기능 수행 후 초기 화면으로 돌아간다
- 잘못된 값 입력 시 `[ERROR] ` 프리픽스와 함께 `IllegalArgumentException` 을 발생시킨 후 애플리케이션을 종료 한다.

## 출석 확인(등록)
- 닉네임과 등교 시간을 입력하는 것으로 출석한다
- 출석 후 출석 기록을 확인한다
    - 출석 등록하면 해당 출석 기록을 출력한다
- 이미 출석한 경우 다시 출석할 수 없으며 수정 기능을 이용하도록 안내한다

## 출석 수정
- 닉네임, 수정하려는 날짜, 등교시간을 입력해 출석을 수정한다
- 작업 완료 시 변경 이전 출석과 변경 이후 출석 기록을 출력해준다
    - `12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!`

## 크루별 출석 기록 확인
- 닉네임을 입력해 출석 기록을 확인한다

## 제적 위험자 확인
- 조회 전날까지의 출석 기록을 바탕으로 제적 위험자를 파악한다
- 출력은
    - 제적 대상자, 면담 대상자, 경고 대장자 순으로 출력한다
    - 대상 항목별 정렬 순서는 지각을 결석으로 간주하여 내림차순한다
        - 지각 + 결석 총 숫자로 내림차순
        - 총 숫자가 같으면 닉네임으로 오름차순 한다

#  도메인

- `Crew`
    - 필드
        - `String nickName`
        - `List<Attendence>`
        - `Indication currentStat`
    - 메서드
        - `Indication getIndication`: 결석, 지각 카운트를 통해 자신이 무슨 대상자인지 판단 할 수 있다
- `Attendence`
    - 필드
        - `Day day`
        - `Absent absent`
        - `Late late`
- `Absent`: Record
    - 필드
        - `int count`
- `Late`: Record
    - 필드
        - `int count`
- `Indication`: Enum
    - 상수
        - `WARN(경고 대상자`
        - `CONSULT(면담 대상자`
        - `EXPULSION(제적 대상자`
        - `NONE(이상 없음`
    - `String description`
- `Crews`: `Crew` 의 일급 컬렉션
    - 필드
        - `List<Crew> crews`
    - 메서드
        - `Crew findByName(String target)`


- `Month`
    - 필드
        - `int monthNumber`
        - `Day day`
- `Day`
    - 필드
        - `int dayNumber`
        - `DayOfWeek dof`
