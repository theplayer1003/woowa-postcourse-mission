# 편의점
- [ ] 구매자의 할인 혜택과 재고 상황을 고려해 최종 결제 금액을 계산하고 안내하는 결제 시스템

# 기능 목록 정리
- [ ] 애플리케이션이 구동되고 resource 를 읽어 Inventory 를 초기화 한다
    - [ ] CsvReader 구현
    - [ ] 상품 구매 시도 시 재고 수량을 파악해 결제 가능 여부를 확인한다
    - [ ] 고객이 상품을 구매하면 재고에서 수량을 차감한다
    - [ ] 시스템은 최신 재고 상태를 유지하며.. -> 파일을 새로 쓰란 뜻..??
- [ ] 사용자는 상품의 가격과 수량을 입력한다
    - [ ] `[콜라-3],[에너지바-5]` 전용 파싱 클래스
- [ ] `총구매액 = 상품별 가격 * 수량`
- [ ] 프로모션 할인
    - [ ] 프로모션 할인이란 1+1, 2+1 등을 의미한다
    - [ ] 프로모션 종류는
        - [ ] 탄산2+1, 2, 1, 2024-01-01, 2024-12-31
        - [ ] MD추천상품, 1, 1, 2024-01-01, 2024-12-31
        - [ ] 반짝할인, 1, 1, 2024-11-01, 2024-11-30
    - [ ] 프로모션 기간이 존재한다. 현재 날짜가 기간에 맞는지 검사한다
    - [ ] 한 상품에 하나의 프로모션 행사만 존재한다. 콜라가 1+1 이면서 2+1 일 수 없다
    - [ ] 프로모션 전용 재고가 따로 존재한다
    - [ ] 프로모션 재고가 부족할 시 일반 재고를 이용한다
    - [ ] 프로모션 대상 상품을 해당 수량보다 적게 가져온 경우, 프로모션 혜택에 대해 안내한다
        - [ ] 이후 추가 여부 를 입력 받는다, Y면 바로 추가, N이면 기존 주문 그대로 처리
    - [ ] 주문량 보다 프로모션 재고가 부족한 경우 일부 수량을 혜택 없이 결제해야함을 안내한다
        - [ ] Y 일 경우 일부 수량을 결제, N일 경우 프로모션 적용 분만 결제 진행
- [ ] 멤버십 할인
    - [ ] 멤버십 할인 적용 여부를 입력 받는다. Y, N
    - [ ] 멤버십 회원은 프로모션 미적용 금액의 30%를 할인 받는다
    - [ ] 최대 한도는 8,000 원 이다
- [ ] 최종 결과 영수증을 출력한다
    - [ ] 영수증 출력 후 추가 구매를 할지 종료할지 선택한다, Y, N
    - [ ] 영수증 구성 요소
        - [ ] 구매 상품 내역
            - [ ] 상품명, 수량, 가격
        - [ ] 증정 상품 내역
            - [ ] 프로모션으로 무료 제공된 상품 목록, 상품명 수량
        - [ ] 금액 정보
            - [ ] 총 구매액, 전체 상품 수량과 총 금액
            - [ ] 프로모션에 의한 할인 금액
            - [ ] 멤버십에 의한 할인 금액
            - [ ] 최종 결제 비용
- [ ] 사용자가 잘못된 값을 입력하면 적합한 예외를 발생시키고 다시 입력 받는다

## 흐름
- 물건 구매 흐름
    - 프로모션 적용 여부
        - 프로모션 대상품목인지?
        - 프로모션 기간인지? 해당 클래스에서 `now()`
        - ....




- Service 는 Controller 로부터 주문Dto 를 받는다
- Service 는 DomainParser 에게 Dto를 넘겨 분해를 요청한다
    - DomainParser 는 `Map<String, Integer> 로 반환한다
- Service 는 Inventory 에게 주문 목록 맵을 넘겨주며 PromotionCheckResult 를 요청한다
    - Inventory 는 맵을 순회하면서 물건을 빼내 프로모션을 검증하고 결과를 계산해 반환한다
- Service 는 PromotionCheckResult를 반환한다


- Controller 는 PromotionCheckResult 를 보고 사용자에게 추가적인 질문을 한다
- Controller 는 추가 질문의 결과와 주문을 Service 에게 넘기며 최종 계산을 요청한다
