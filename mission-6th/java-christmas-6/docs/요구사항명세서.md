## 도메인

### 주문

- Order: 주문 전체를 다루는 클래스
    - 필드
        - OrderItems
        - VisitDate
- OrderItem: Menu 와 수량을 다루는 클래스
- OrderItems: OrderItem 을 다루는 일급 컬렉션
- VisitDate: 방문 날짜를 다루는 클래스


- Menu
    - 필드
        - MenuType(Enum): 에피타이저, 메인, 디저트, 음료
        - String menuName;
        - int menuPrice;

- OrderFactory: 파싱된 사용자 입력 정보를 받아 Order 객체를 생성
- OrderParser: 사용자 입력 정보를 도메인에 맞게 파싱

### 혜택

- Event: 이벤트 전체를 다루는 클래스
    - EventPolicy(Interface): 이벤트 적용 조건
        - boolean isSatisfied();
        - BenefitResult apply();
            - DdayEventPolicy
            - WeekdaysEventPolicy
            - WeekendEventPolicy
            - SpecialdayEventPolicy
            - GiftEventPolicy
- Badge: 배지 부여
    - BadgeLevel(Enum): 별, 트리, 산타

- EventFactory: Order 객체를 통해 Event 를 생성

### Dto

- Request
    - OrderRequestDto
        - Integer visitDate
        - String orderRequest
- Response
