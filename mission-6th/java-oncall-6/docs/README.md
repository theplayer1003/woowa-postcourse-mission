# 프로그램 목적

- Oncall 은 사용자에게 월 과 요일을 입력 받고 평일, 휴일 비상 근무 사원 순서를 입력 받으면 근무자가 연속되지 않도록 한 달의 비상근무 표를 작성해주는 프로그램 이다.

# 규칙

- [x] 평일은 월, 화, 수, 목, 금 을 뜻한다
- [x] 휴일은 토, 일 과 법정공휴일 을 뜻한다
    - [x] 법정공휴일은
        - 1월 1일 신정,
        - 3월 1일 삼일절,
        - 5월 5일 어린이날,
        - 6월 6일 현충일,
        - 8월 15일 광복절,
        - 10월 3일 개천절,
        - 10월 9일 한글날,
        - 12월 25일 성탄절 이다
- [ ] 평일과 휴일 비상 근무 순번이 존재한다
- [ ] 모든 비상 근무자는 평일, 휴일 순번에 한 번씩만 편성되어야 한다
    - [ ] 근무자가 A, B, C, D 일 경우
        - [ ] 평일 비상 근무자: A, C, D, B
        - [ ] 휴일 비상 근무자: D, C, B, A
- [ ] 모든 비상 근무자는 2일 연속 근무할 수 없다
    - [ ] 연속으로 배정되는 경우 이틀 째 근무날을 그 다음 근무자와 교체한다

- [x] 근무자는 닉네임을 가진다
    - [x] 닉네임은 중복될 수 없다
    - [x] 닉네임은 최대 5자 까지 허용한다
- [ ] 비상 근무자는 최소 5명이 필요하다
- [ ] 비상 근무자는 최대 35명까지 허용한다

- [ ] 연도는 고려하지 않는다
- [ ] 2월은 항상 28일까지만 있다고 가정한다
- [ ] 올바르지 않은 입력을 처리 할 경우 `[ERROR]` prefix 를 붙여 에러메시지를 출력하고 다시 입력 받는다
- [ ] 입력 받은 월과 요일이 올바르지 않은 경우 월과 요일을 다시 입력 받는다
- [ ] 입력 받은 평일 순번과 휴일 순번이 올바르지 않은 경우 평일 순번과 휴일 순번을 다시 입력 받는다 (휴일 순번이 틀려도 처음부터 다시 받는다)

- [x] 평일이면서 법정공휴일의 경우 결과 출력시 `(휴일)` 표기를 해준다

# 상태

- 월
- 요일
- 평일 비상 근무 리스트
- 휴일 비상 근무 리스트

- `Month`
    - 책임
        - 일 들을 관리하는 일급 객체
    - 필드
        - `List<일> days`
        - `int monthName`
    - 메서드
        - ...
- `Day`
    - 책임
        - 해당 날이 평일인지? 휴일이거나 법정 공휴일인지? 판단한다
    - 필드
        - `int dayNumber`
        - `DayOfWeek`: Enum
        - `LegalHoliday`: Enum
            - `int month`, `int day`, `String description`
            - `String getSuffix`
    - 메서드
        - `boolean isWeekDay()`
        - `boolean isWeekendOrHoliday()`
- `MonthFactory`
    - 책임
        - 월 과 요일을 받아 달력을 생성한다

- 근무 순서 편집기
    - 책임
        - 평일 근무 순번과 휴일 근무 순번을 받아 알맞게 배치한다
    - 필드
        - `Deque<Staff> weekday`
        - `Deque<Staff> holiday`
    - 메서드
- 비상 근무표
    - 책임
        - 비상근무 배정 결과를 추상화
    - 필드
        - ...
    - 메서드
        - ...

- `Staff`
    - 책임
        - 사원 한명을 추상화
    - 필드
        - `StaffName name`: record
    - 메서드
        - `getter`
        - `equals HashCode`
